# Customer Churn Prediction using Machine Learning
## Project Overview
This project predicts whether a customer is likely to leave a telecom service based on customer demographics, account information, and service usage patterns. The objective is to help businesses identify customers at risk of churn and take preventive actions to improve customer retention.
## Dataset
Total Records: 7043
Features: 21
Target Variable: Churn
Source: Telecom Customer Churn Dataset
